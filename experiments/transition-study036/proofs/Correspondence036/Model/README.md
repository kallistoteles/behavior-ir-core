# Restricted model and native boundary

The model quantifies over arbitrary finite parent/child universes. The reference
enumerates the universe; the candidate changes one point. Parent phases remain
Open/Gone/Abandoned, terminal finish still advances the coordinate, allocation
facts and ordered commands remain unchanged. The independently specified root
types in targets.json precede the actual type/axiom/fresh-kernel audit.

`OriginalEncoders` is a parametric interface to unchanged original Core encoders.
Its outputs are complete concrete ordered trees, including arbitrary nested
fields, rather than a Boolean equality premise. `finish_exact` derives equal
state and complete trees from independent state algorithms. It does **not**
prove that a Rust evaluator supplied those trees from the modeled state. The
field inventory and entire-value oracle checks address that native bridge;
without a formal Rust/encoder/observer correspondence the native claim remains
conditional. No field projection or equal final-state-only test is accepted.

`semantic_work_bound` is an explicit five-access model trace with independent
nonnegative physical completion charges. This is not a proof that native map
operations, record construction, canonical hashing or history handling are
constant time. Native physical counters must establish their separate scope.

`promote` requires matching subject, lineage and position, an existing child and
representable successor, and an Applied receipt. The binding of that receipt to
actual backend publication remains a native/host obligation. Uncertainty never
creates authority. The model is not a durability or writer authentication proof.

`valid` is linked by equivalence and operation commutation to the pinned Safety
lifecycle R/P theorem. Program-level FieldOwnership certification is a separate
original Safety obligation, not inferred from this state theorem.
