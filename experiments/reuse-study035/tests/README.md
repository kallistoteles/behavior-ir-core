# Test protocol

Use the exact installed tools bound in ../toolchain.json and the owned Nix environment. Write/review/observe intended assertion red before implementing acceptance. Missing compiler/import/collection errors are not intended red. Run one heavy child at a time through035 recorder once available; record actual logs, clocks, sources and empty process tree. Detailed work mode stays separate from three timing observations; all normative results remain identical. No live model/network dependency.
