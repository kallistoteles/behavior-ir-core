# T021 — explicit full Q and real-calendar time

Compiled T006 regressions previously accepted malformed Gregorian dates,
missing/null-confused Q, unequal expected values and wrong context types.
Baseline `/tmp/013-T006-reviewed-red.log`.

Full Q now has a canonical identity and exact closed Bool/i64/String product
under its execution policy. Time accepts only real Gregorian UTC seconds for
years 0001–9999. All roles use explicit [start,end) eligibility; waiver expiry is
strictly after policy_time. Bound requested time must equal actual bundle time;
unbound time must be explicit null. No clock or implicit default is consulted.

Context/calendar/role/expiry cases pass in `/tmp/013-T020-T022-progress.log`.
Independent live-context comparison and archived recovery remain pending Store
integration, and are not inferred from the mere existence of a signed Q.
