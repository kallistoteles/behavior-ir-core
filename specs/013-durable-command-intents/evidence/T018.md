T009 produced five actual acceptance defects: invalid/erroring seed invariants,
unbound entity invalidity after same-schema behavior changes, zero-binding bypass
and healing an already-invalid global invariant. Baseline `/tmp/013-T009-red.log`.

Store genesis, read/evaluate/invoke and commit rederivation use it independently
of action bindings. Typing, every entity constraint/invariant/reference and every
global invariant must hold without evaluation error. Validation facts derive
from complete loaded values and references rather than optional query indexes.
Partial legacy standalone evaluation and its published record bytes are unchanged.
The complete keys/version and atomicity guarantees of a custom backend remain
an explicit storage trust boundary, not a theorem about adversarial storage.

run `/tmp/013-T018-final-legacy.log` passed 42 tests including those eight and
existing commit, query, invocation/history and migration checks. The old schema
mismatch diagnostic retains precedence over the new behavior-pair mismatch.
