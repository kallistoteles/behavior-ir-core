# Earlier prototype design

[design-before-plan.json](design-before-plan.json) preserves seven prior design
artifacts verbatim with SHA256 digests and their original relative-path base.
They were created before planning was requested and are historical evidence,
not current 015 requirements or an approved implementation design.

The active plan is [../plan.md](../plan.md). Prototype source/tests, benchmark
samples and recorded gates are retained separately; none establishes acceptance
of the revised plan. The archived Markdown content retains its original relative
links inside JSON rather than creating misleading live links from this directory.

[tasks-before-regeneration.json](tasks-before-regeneration.json) preserves the
superseded prototype task list verbatim with its SHA256 digest. Its checked entries
describe historical activity, not acceptance of the current plan. The active
[../tasks.md](../tasks.md) was generated separately with all tasks unchecked.
