# Initial Store creation contract implementation

019 implements one current Backend initialization law: public storage is absent
or a complete original Store. A failed or lost response may leave publication
unknown to the caller; it never makes private staging authoritative. Equivalent
original-request retry recovers the same lineage, preserving all later history,
while an established complete foreign creation yields a stable conflict.

## Changes

Core factors its existing complete seed validator into private candidate evidence.
Create validates first, performs a bounded preflight/publication/recovery algorithm,
checks actual original and captured current material, and preserves original
operational errors unless complete foreign publication is positively established.
Generic opening checks structural publication/history/schema and stays cold.
Exact Module-bearing recovery adds normalized seed/reference checks. Only exact
verified captured H0 may attach an existing history/Module/profile-bound initial
certificate; it cannot certify later positions after a concurrent commit.

InMemory constructs privately and assigns once, or recognizes equivalent original
creation without resetting current storage. The durable test consumer uses one
stable cooperative lock, private file construction, file synchronization, atomic
rename and directory synchronization; recovery establishes the equivalent barrier
without rewriting advanced snapshots. Private orphaned staging remains invisible.

Public signatures, facade exports, Wire/schema/hash/record domains, historical
profiles and verifier results are preserved. The mandatory Backend behavior change
is minor-class under current policy; no numerical version, tag, release, merge or
ecosystem pin was changed. External hosts must follow the
[migration guide](../../docs/backend-creation-migration.md).

## Assessment and limits

[Targeted re-audit](evidence/targeted-re-audit.md) maps all 16 obligations and G3/G8/
G9/G11/G12 to laws, code invariants, executable evidence and assumptions.
[Independent Core](evidence/independent-core-review.md) and
[host/reference](evidence/independent-host-review.md) reviews found no remaining
material creation-boundary contradiction under those premises. Full immutable
Backend history/enumeration, cryptographic identities, stable cooperative locks,
atomic namespace replacement, a durably established root and honest sync/device
behavior remain assumptions. Generic legacy opening is not full typed Ref/Behavior
validation; bounded endpoints are not full-prefix replay. Process exit is not
power-loss evidence.

The [existing trusted-v2 query-commit parsing defect](evidence/follow-up-findings.md)
was reproduced independently of ordering/index mutants and remains open. It was
not patched or called unsupported under 019. This bounded assessment preserves016
as evidence and does not close unrelated020/021 findings or declare all Core sound.

Actual complexity is disclosed: current original-key filtering is O(t*s) for t
schema types and s seeds, incoming comparison O(s*r0), plus sorting/hashing/full
seed validation and bounded endpoint/schema-history reads. Reference recovery
clones storage; the test durable host parses and syncs snapshots. The planning
linear sketch is not an as-implemented guarantee or a constant-latency promise.
