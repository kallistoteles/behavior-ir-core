Safety certification and checking happen at program admission and renewed trust boundaries. Any measured ordinary-operation endpoint must retain those prior costs and the exact authority it reuses. A new process cannot acquire the in-process checked-program capability from the assessment JSON; it must independently recheck or name an explicitly trusted retained-storage basis. The pilot does not implement such durable trusted storage.

Every full subject includes the exact final BehaviorHash, complete Safety Policy set, schema/profile, accepted origin, interval and expected HistoryRef. The Rust public port uses a distinct source location and identity from the Python reference and obtains its own certificate. LD8C changes the admitted action inventory and must be freshly certified separately, even if the added action changes only command history.

The new formal model is deliberately small. `CoveredStep` includes the imported checked-module, complete-action, guard-probe interpretation, ordinary Core-condition and exact projection-execution premises; its constructor does not assume a safe post-state. Complete native Rust, Core serialization/hashing, extraction/projection, backend completeness, all-writer enforcement and physical storage correspondence remain outside the theorem. Reusing abstract Core032 exact-observation checking does not establish a native LD8 interpreter bridge or a cryptographic circuit bridge.

The current development artifacts retain operational/compiler failures separately from semantic countermodels. A failed Lean compile or a bounded tool stop is never an invalid-business-transition result or a universal mathematical disproof. Final E01–E15 dispositions and B/C arguments will be completed against closed campaign evidence.

## B and C: authority and actual work

B now reconstructs the entire original public backend packet in its own Store, checks public data and behavior replay, re-executes independently expected requests, compares every original invocation and captured backend argument, and directly checks every requested historical state under the complete original policies. Q4 in this implementation follows those state checks, not a producer's claimed certificate coverage. This does not give B Q1, external enforcement, latest-head authority or Q6. The producer cannot select the accepted endpoint: the controller binds it independently. B shares the pinned Core implementation, so independence from producer acceptance is not semantic implementation diversity.

Resident B owns a non-deserializable checked basis. Extension consumes that basis, checks its exact parent, evaluates the incoming request itself and compares the complete candidate before committing. Failure discards the basis. Restart and loss require re-establishment; serialized flags confer no authority. Public Core may still traverse previous history internally. The campaign charges establishment separately and measures that implementation rather than promising O(delta) execution.

C retains the strong 033 contract unchanged. The seven bound prior artifacts distinguish primitive identity/hash costs, a timed-out actual compact-prefix attempt with no completed certificate, sampled resource scopes, corrected versus invalid SQLite archive attempts, and an older local-K fragment. None certifies this LD8 subject. No new C prover is scheduled. A primitive completed proof or unrelated storage experiment cannot fill the missing complete prefix, correspondence and durable publication obligations.
