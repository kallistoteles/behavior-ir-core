# Restricted laws and executed constructs

The twelve Lean roots are finite typed-model theorems, checked with independently
specified types, transitive axiom checks and fresh kernel replay. This register
connects those constructs to the actual research implementation. It does not
turn the Rust compiler, storage host or native evaluator into a proved Lean
implementation.

| Construct | Model and actual source | Connection and remaining premise |
| --- | --- | --- |
| Admitted fragment | `State.lean`, `eligibility.rs: module/finish`; exact original LD8 wire plus original three-policy hash | All eight actions and original source locations remain. Existing child, exact history and representable successor are checked. Only finish uses the accelerated path. Changed full wire/profile/policies, commands, malformed/missing bindings and other actions retain ordinary Core. Native restriction has executable conformance evidence; no universal Rust refinement proof. |
| Reference and point transition | `Reference.lean: referenceRows/referenceAfter`; `Incremental.lean: incrementalAfter`; original Core scalar execution and `views.rs: stage/apply` | Independent full enumeration and point definitions have equal exact typed outcomes, including Terminal→Terminal. Rust still executes the original scalar engine, not a second language implementation. Its coupling to the typed model remains a named premise. |
| View relation | `Views.lean: view_update_exact`; `views.rs: seed/materialize/apply`; `version-views.patch` | Seeds come from actual original validated versions. Original identities, versions and R/P are reconstructed, then only the confirmed child/owner bucket/version entries change. Owned maps are updated in place; complete maps are not cloned to stage a point update. Native reconstruction/audit checks establish finite conformance, not a general native theorem. |
| Scalar results and observer recipes | `Observation.lean`; unchanged Core `eval/prepared.rs` templates; `prepared-invocation.patch` | Existing Core reuses cached stable row contributions and ordinary scalar evaluation for the changed row. Fresh invocation uses the original resolver and shared envelope builder with current coordinates. Unsupported paths retain original first-error/skipped/command behavior. Memo/observer/native projection fidelity remains conditional beyond tested cases. |
| Complete observation | `ObservationModel.lean: OriginalEncoders/completeObservation`; `observation-fields.json`; `observation.rs: execute_original/complete_original` | The model preserves complete ordered trees supplied by the unchanged original encoder interfaces; encoder fidelity is external, not an assumed equality of two outputs. Native comparison retains complete invocation, bundle, captured commit arguments/record, histories, post-state and original property outcomes. No shared field projection is accepted. |
| Original identities and required bytes | Original Core invocation/record/documents/canonical code; version-view identity uses the existing private `SnapshotIdentity` | No replacement state/history/event hash or compact evidence format. Mandatory whole observations, hashing, allocation and history-vector relocation are separately charged. Exact allocation/shared-page figures remain unavailable, not zero. |
| Writer/host | Private owned `Ground/Parent/Store<Capture>`; original Backend contract | All actual memory writers must stay inside the owned boundary. No deserialized success flag creates a capability. Backend consistency/immutability, original cryptographic assumptions, compiler/tool fidelity and exclusive writer control remain explicit premises. |

A missing or conditional connection stays missing or conditional in the final
assessment. The original direct-report caller contract is frozen separately;
independent post-operation audits cannot be relabelled as candidate checks.
The first final campaign has not yet been frozen or measured at this checkpoint.
