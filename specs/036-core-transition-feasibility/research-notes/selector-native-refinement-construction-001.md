# B01 construction over the actual selector and its callers

This is a source-only construction note for T060/B01. It proposes work for a later source revision; it contains no implementation, extraction, kernel-check or native-refinement result. No build, test, probe, download, process inspection or large generated IR read was performed for this note. Native329, its supplied 77 tests and twelve full original finite comparisons are unchanged. B01–B10, T052 and T059 remain open; no accepted measurement is created here.

The next useful proof target is the result and branch behavior of the **actual** `eligibility::module`, `eligibility::finish`, `Views::matches`, `Views::stage` and their `Ground` callers. A theorem about `routed false ordinary optimized` cannot supply this: the existing theorem reduces a supplied Boolean, without connecting that Boolean or either callback to Rust. The contract requires the real selector and equal complete fallback inputs, for arbitrary finite representable states, and separately requires source/model/compiler binding. [existing template](/data/repos/behavior-ir-core-033/experiments/transition-study036/proofs/Correspondence036/Model/Reuse035/Exact.lean:21), [B01 and domain](/data/repos/behavior-ir-core-033/specs/036-core-transition-feasibility/contracts/correctness.md:5), [T060](/data/repos/behavior-ir-core-033/specs/036-core-transition-feasibility/tasks.md:120), [bridge contract](/data/repos/behavior-ir-core-033/specs/036-core-transition-feasibility/inputs/v2/native-bridge-contracts-186.json:11).

## 1. Exact decision sequence to preserve

`eligibility::module(parent)` first decodes the compile-time bytes of `expected/ld8-module.json` as UTF-8. Decoding failure returns false. On success it compares the complete `serialization::module_wire(&parent.module)` string with `expected.trim()`, and only if equal compares `parent.analysis.policy_set_hash()` to the literal `sha256:dd15224cdcb1f74cf061420e0eccf15e912611503fc36b461ed231b5772ec4b5`. `module_wire` is a concrete call to the original `behavior_engine::serialize::to_wire_json`, rather than a structural Module comparison. [module source](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/eligibility.rs:5), [concrete codec call](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/serialization.rs:11).

`eligibility::finish(parent, checked_view, history, request)` evaluates the following failures in source short-circuit order; the first seven guards form one `||` expression. A failed eligibility check exits `None`, not an original refusal:

| Order | Actual check / operation | Exact result needed |
| --- | --- | --- |
| 1 | `!module(parent)` | None on false module match; preserve the byte/trim/policy calls above. |
| 2 | `!checked_view.matches(history)` | None unless `trusted && view.history == *history`, using full native history equality. |
| 3 | `history.position == u64::MAX` | None at MAX; positions below MAX remain eligible. |
| 4–7 | Index `format`, `capability`, `input`, `context` | Require respective equalities to `"behavior.invocation.v1"`, `"finish"`, empty Object, empty Object. |
| 8 | `request["bindings"].as_object()?` | None for missing or non-object bindings. |
| 9 | `bindings.len() != 1` | None unless exactly one binding key exists. |
| 10 | `bindings.get("c")?` | None unless that sole key is `c`. |
| 11 | `binding["entity"] != "Child"` | None on missing/wrong/non-string entity. |
| 12 | `binding["id"].as_str()?` | None on missing or non-string ID. |
| 13 | `checked_view.stage(child)?` | None unless the actual stage succeeds; its returned delta is discarded here. |
| 14 | `Some(child.to_owned())` | Return exactly the complete UTF-8 ID, without parsing, normalization or an authored-fixture bound. |

The numbered rows describe source operations, not an implementation to substitute for them. Their owning bodies are [finish](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/eligibility.rs:16), [matches](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:178) and [stage](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:221).

`Views::stage` has a second exact sequence: reject untrusted view or MAX view position; look up and clone child row; look up its owner in parents; reject `(old.phase == "Active" && parent != "Open")`; look up the owner's active bucket; compute its membership for this child; reject membership different from `(old.phase == "Active")`; construct `FinishDelta` with the old full view history, exact child string and cloned old row. It does not inspect the version map. `matches` has already equated the history in `finish`, but `stage` has its own MAX check and can be called separately. [stage source](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:221).

Two consequences must survive the specification:

* A Terminal child can select with an existing Gone or Abandoned owner and absent active membership. Requiring Open for every finish would silently narrow the actual fragment. In a properly seeded view, phases are restricted to the source enum spellings; Active children require Open. [seed phases](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:70), [seed ownership and lifecycle](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:106).
* Raw `stage` does **not** validate the phase enum or the entire view. For an arbitrary generated `Views` value, a phase other than Active with matching false membership can pass. The sound fragment theorem therefore needs the proved source-reachable view relation; the exact result theorem should still describe the raw body on all of its representable inputs. `trusted` alone is not the mathematical invariant. Only successful `seed` sets it true after all row and relation checks; invalidation clears it. [construction](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:146), [invalidate](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:181).

There is no check for extra top-level request fields, nor for extra fields inside the `c` binding. Only the binding **map** has an exact length check. Thus the exact selector theorem must include these values, even if the later original decoder rejects them. Selection is not a promise that original invocation decoding/evaluation succeeds. Request IDs are native strings: the selector imposes no prefix, decimal encoding, fixture size, or text length limit. `commit_time` is not checked here at all. [request checks](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/eligibility.rs:25), [metadata type](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/fixtures.rs:306).

## 2. Actual calling context and fallback boundaries

At the measured endpoint, `run_one_operation` takes a pair `(Value, InvocationMetadata)` by reference and passes both components to `ground.invoke_with_metadata`. The outer pair loop indexes the actual two requests in order. The wrapper then compares the whole actual observation to the supplied original and performs delivery; neither the finite two-request loop nor the five authored growth cases is the selector theorem's state-size bound. [operation call](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/operation.rs:126), [two-request loop](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/operation.rs:210), [fixture dimensions](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/reference.rs:25).

The relevant caller sequence is:

1. `invoke_with_metadata` clones its exact-history receipt or returns `Prerequisite("UnestablishedGround")`, then passes `expected`, **the same request**, and **the same metadata** to `invoke_expected_with_metadata`. That method first checks Established status, then exact receipt equality; stale receipt quarantines and returns `StaleGround`. These errors occur before selection and must not be reclassified as selector fallback. [entry wrappers](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:114), [preconditions](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:137).
2. It clears selected retention if disabled; diagnostics may update allowed rows from request child and view owner; it sets Pending. If `use_views` is false, it disables prepared use and calls `original_step_marked(request, metadata)`. This is a real fallback edge in addition to the two inside `view_step`. [pre-routing effects](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:150).
3. `view_step` first tests evidence-is-Some, then at-is-Some, then module failure. Any true test disables prepared use, increments enabled fallback diagnostics and calls `original_step_marked(request, metadata)`. In particular, nonlegacy `commit_time` alone does **not** force fallback; an empty evidence payload still does when wrapped in Some. [early route](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:277).
4. Otherwise it obtains the actual current history. With retention disabled it runs the original parent validator; non-Valid returns `ViewParentReestablishmentFailed`, and seeding failure propagates. With retention enabled it rebuilds missing/mismatching views. These errors precede the finish selector and are not an original fallback result. [history and repair](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:292).
5. It calls the actual `eligibility::finish` on Some view, otherwise takes None. On None it disables prepared use, updates diagnostics, invalidates any view, calls **ordinary_step with the unchanged request and metadata**, and rebuilds if the resulting property status is Valid. A rebuild error can occur after the original operation: proving just the ordinary invocation equality does not prove the caller's eventual Result equality. [selector/fallback edge](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:319).
6. On Some child it stages that same child again; None now yields `MissingCheckedViewDelta`. It enables prepared use and calls `observation::execute_original_with_metadata` with the actual mutable Store, actual module, complete unchanged request and metadata. Promotion checks actual bundle/last-call/view in that order. Failed promotion invalidates and performs actual original property/state reconstruction; it does not undo the invocation. [selected route](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:341), [promotion and recovery](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:355).

`ordinary_step` itself calls `execute_original_with_metadata`, then the original snapshot validator on `(module, analysis, store, step.after)`, then `reference::state_facts`, then `complete_original`. Its marker wrapper preserves the actual error. The reference wrapper uses the same native invocation helper and original commit method, but it is not the identical complete wrapper: the ground path includes timing arithmetic and management effects. [ordinary_step](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:231), [marker](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:267), [reference wrapper](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/reference.rs:89), [timed original wrapper](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/observation.rs:27).

The full common invocation boundary is concrete: serialize the **whole native request Value** with `document.to_string()`, call the original `RequestedInvocation::decode`, propagate decode failure or original error list, then call `s.invoke(m, &request, &metadata.commit_time, metadata.evidence.clone(), metadata.at.as_ref())`. Do not replace that argument vector by action/child alone. The receipt/history, Store facts/head/backend state and actual module remain caller context; analysis is used by the original validator, and the complete invocation/bundle/commit record/history/state/property values are used by the observation constructor. [actual native helper](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/fixtures.rs:332), [commit and observation](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/reference.rs:96), [normative observation arguments](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/serialization.rs:39).

## 5. Minimal expected theorem family

The following is **uncompiled type-level notation**: `G.f` must be replaced by the actual imported generated function constant and its exact arguments/Result/borrow-return types. `Native` means the generated native structures, not a replacement hand-written state. The right-hand mathematical predicates below are definitions from explicit field/lookup equations in sections 1–4; none is a desired equality hypothesis, opaque result function, or Bool supplied by a caller.

```lean
-- Exact native selector laws, with all dependency instances already concretely bound.
module_exact (p : Native.Parent) :
  G.eligibility.module p = Result.ok (nativeModuleMatch p)

matches_exact (v : Native.Views) (h : Native.HistoryRef) :
  G.views.matches v h = Result.ok (v.trusted && nativeHistoryEq v.history h)

  G.views.stage v id = Result.ok (stageSpecFromNativeLookups v id)

    (h : Native.HistoryRef) (r : Native.Value) :
  G.eligibility.finish p v h r = Result.ok (finishSpecFromNativeFields p v h r)

-- No premise asserting a safe/equal child; derive fragment facts from source reachability.
finish_fragment (p : Native.Parent) (v : Native.Views)
    (h : Native.HistoryRef) (r : Native.Value) (id : Native.String)
    (vr : CanonicalReachableView p v h)
```

## 6. What same-original congruence does and does not discharge

After proving same actual function identity and equal **complete** arguments at a call, ordinary function congruence can relate the two unchanged calls, including the original serializer/hash where appropriate. No SHA reimplementation is needed solely for equal applications of that same function. [congruence contract](/data/repos/behavior-ir-core-033/specs/036-core-transition-feasibility/contracts/correctness.md:42).

The missing work here is the native instantiation: native request serialization/decode arguments, commit_time/evidence/at, module, before/current history, mutable Store facts and performed error/effect conditions. Disabling prepared use or rebuilding views changes a receiver's management state, so one cannot assert literal Store equality across all paths. Prove that the relevant original execution state/arguments agree and that differing management state has the required noninterference. On the selected path the prepared evaluator is genuinely a separate B05 obligation. Native map projection, Safety projection, lookup/absence preservation, phase update and full observation construction remain proofs; an arbitrary `originalEncoder` or `originalEvaluator` callback with their desired result is not a discharge. [actual prepared selection](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:347), [B02–B07](/data/repos/behavior-ir-core-033/specs/036-core-transition-feasibility/contracts/correctness.md:18).

The old exactness result constructs both observations with the same parameterized `completeObservation` encoder after proving a model-state equality. It cannot establish the equal native arguments just listed. [old exactness](/data/repos/behavior-ir-core-033/experiments/transition-study036/proofs/Correspondence036/Model/Reuse035/Exact.lean:12).

## 8. Concrete implementation order after the source-frozen run

1. Resolve the exact generated selectors/stage/matches/caller signatures and finite transitive call slice from the selected new extraction. Bind all source/config/compiler/feature/instance identities; do not scan or translate an unrelated larger closure to avoid a missing selector dependency.
