# Source-bound native dependency refinement: proposed minimum

Research only, 2026-11-18. No proof, task completion, new extraction, build or test is claimed. The live actual327 probe was not inspected or modified. This note reads current repository Rust, actual326 generated files, pinned dependency sources and the existing contracts. References to the private Core source below identify the extracted source paths recorded by actual326; the final native/stable versus analysis/compiler binding remains a separate obligation.

## Finding

The smallest honest route is a **strong representation-preserving relation**, finite ordered collection models with an explicit runtime boundary, translated application adapters, and shared-original-call congruence at the last unchanged codec/hash calls. There is no need to prove all IEEE arithmetic for values merely carried through as metadata. There is a need to preserve their exact variant and floating-point representation and to distinguish that relation from Rust `PartialEq`. Collection models and codec callbacks alone do not establish their linkage to native execution.

The current correctness contract explicitly permits translated source, justified generic runtime primitives, and congruence after equal complete arguments and compatible calls/errors/effects; it separately forbids hiding projection/evaluation/observation equality in those boundaries. The proof contract has only `propext`, `Classical.choice`, `Quot.sound` in its kernel axiom allowlist, no checked native roots and no frozen native expected types. Correspondence-002 has all B01–B10 unestablished and calls its direct call graph incomplete for indirect dispatch. These are open requirements, not obstacles that may be reclassified as proved. [Correctness contract](../contracts/correctness.md), [proof contract](../inputs/v2/proof-contract-002.json), [correspondence](../inputs/v2/correspondence-002.json), [tasks T053–T070](../tasks.md).

## Kernel axioms, parameters and the native trust boundary

Three distinctions matter:

1. `axiom NativeNumber : Type` declares an uninterpreted carrier. It does not assert that the projection is correct or give a numeric law. Nevertheless, it is a global Lean axiom dependency. Likewise `axiom clone : NativeNumber → Result NativeNumber` declares an arbitrary function, not an identity-preserving clone. The actual326 external templates still contain these kinds of declarations for Number, Map/BTreeMap, Store, JSON operations and codecs. Raw templates therefore cannot silently satisfy the present three-name allowlist. [Actual326 external types](/var/tmp/behavior-ir-core036-v2/w001/native-extraction/a0326/generated/TypesExternal_Template.lean:168), [external functions](/var/tmp/behavior-ir-core036-v2/w001/native-extraction/a0326/generated/FunsExternal_Template.lean:3183).
2. A theorem universally quantified over a carrier and a function, such as `∀ (N : Type) (encode : Json N → Result Bytes), a = b → encode a = encode b`, needs no extra global axiom. This is genuine congruence. Hypotheses named `NativeProjectionCorrect` or `∀ x, nativeEval x = referenceEval x` would instead leave exactly the required theorem open, even if an axiom scanner saw only the three foundations. Expected-type checking must inspect hypotheses as well as global axioms.
3. A constructive Lean model with proved lookup/update laws has a kernel-checked **model** theorem. Identifying it with native std/serde is a separate source/tool/runtime adequacy claim. Either discharge that source refinement, or explicitly identify the narrowly justified generic primitive model as part of the declared compiler/runtime trust boundary permitted by the contract. Never call the model law a proof of that native linkage. The Aeneas README itself describes the external templates as missing hand-written models; its `rust_*` annotations register models with extraction, rather than proving native adequacy. [Pinned Aeneas README](/var/tmp/behavior-ir-core036-v2/w001/tmp/nonpos-source/a0273/aeneas/README.md:153).

Practical consequence: keep diagnostic axiom-filled templates diagnostic. For accepted roots, use concrete definitions for modeled primitives and source-refined adapters. For honest arbitrary shared functions, introduce explicit parameters through a prospectively specified extraction/model interface (or actual shared Rust callback seam). The current generated functions reference fixed global externals; simply restating a client theorem with a parameter does not replace those references. Do not edit generated bodies to perform the replacement. A prospective change must preserve/re-extract the same executable call sites, freeze exact expected types, and classify every runtime/model binding outside the kernel separately. If the existing contract is intended to exclude even that declared runtime modeling boundary, source refinement/tool extension is required; relaxing an axiom check alone cannot close the feature.

## JSON and Number: preserve representation, avoid unnecessary arithmetic

Pinned serde_json 1.0.151 without `arbitrary_precision` represents Number by `PosInt(u64)`, strictly negative `NegInt(i64)`, or finite `Float(f64)`. `PartialEq` compares only like variants; float equality merges positive and negative zero. Its Hash implementation explicitly normalizes the two zero bit patterns. Number serialization dispatches to `serialize_u64`, `serialize_i64` or `serialize_f64`. [Number representation/equality/hash](/var/tmp/behavior-ir-core036-v2/w001/cargo/registry/src/index.crates.io-1949cf8c6b5b557f/serde_json-1.0.151/src/number.rs:20), [serialization](/var/tmp/behavior-ir-core036-v2/w001/cargo/registry/src/index.crates.io-1949cf8c6b5b557f/serde_json-1.0.151/src/number.rs:372). Default features enable std; `unbounded_depth` does not enable `arbitrary_precision`, `preserve_order` or `float_roundtrip`. The final effective feature set must still be bound from the actual source/configuration subject. [Pinned feature declarations](/var/tmp/behavior-ir-core036-v2/w001/cargo/registry/src/index.crates.io-1949cf8c6b5b557f/serde_json-1.0.151/Cargo.toml:65).

Recommended `Json.lean` API:

- Define `Json NumberAtom` recursively with exact strings, ordered arrays and finite object fields. Define a strong relation `SameNativeJson` whose number case preserves native variant/payload, including float bits. With an opaque atom parameter, use Lean identity of the atom; **do not quotient by native PartialEq, numeric value, hash, decimal spelling or old model Nat**. A concrete alternative is `Pos U64 | Neg {i : I64 // i < 0} | Float {bits : U64 // finite bits}`. Its float operations need only finiteness, clone, equality-with-zero-case and serialization dispatch where those operations are used.
- Define a distinct `nativeJsonEq` Boolean with the actual variant-sensitive, signed-zero-insensitive equality; prove strong identity implies that equality. Its converse is false. The current observation comparator already checks serialized bytes in addition to Value equality for this reason. [Comparator](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/observation.rs:5).
- Source-refine `Value::clone`, constructors, `as_str`, `as_object`, `as_array`, `as_u64`, indexing and mutation. In particular read indexing returns Null for a missing key/wrong type, while mutable string indexing can insert Null or panic on a nonobject. Missing and explicit Null are therefore distinguishable through `get` even though bracket reads coincide. [Pinned index implementation](/var/tmp/behavior-ir-core036-v2/w001/cargo/registry/src/index.crates.io-1949cf8c6b5b557f/serde_json-1.0.151/src/value/index.rs:83).
- Prove constructor/clone/frame lemmas preserve every uninspected field and metadata atom, not only fields retained by the mathematical Safety projection. Views read string id/owner/phase, keep full EntityVersions, and construct only string-valued child rows. Eligibility tests strings and empty input/context; ground separately reads history position via `as_u64`. Thus there is no evidenced need for general floating addition/multiplication in this adapter seam. That statement does not discharge arbitrary numeric operations deeper in original Core. [Views](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:54), [selector](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/eligibility.rs:16), [ground](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/ground.rs:185).

Opaque Number is therefore viable for **unchanged arbitrary metadata**, if the relation carries the same atom and every clone/reconstruction is shown to preserve it. It is insufficient to merely let an arbitrary Number type exist and assume clone/encoding behaves correctly. For inspected numbers, provide the actual used operations: `as_u64` returns only PosInt, `from_f64` accepts finite values without discarding the sign bit, and `is_f64` is a variant test. [Number methods](/var/tmp/behavior-ir-core036-v2/w001/cargo/registry/src/index.crates.io-1949cf8c6b5b557f/serde_json-1.0.151/src/number.rs:149).

Parsing is a distinct boundary: `parse_payload_json` admits finite floats; the control-record parser rejects them, and `semantic_digest` rejects Float variants recursively. Preserve the actual depth/byte/duplicate-key/end-of-input and first-error behavior. Never apply the integer-only digest domain to arbitrary semantic payloads. If the same actual parser is called once on equal complete bytes/configuration, its result may remain parametric for congruence. If different wrappers or parsers are compared, their linkage/behavior requires proof. No claim of preserving original textual JSON spelling follows: parsing has already chosen serde's Number representation. [Protocol](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/protocol.rs:24), [parser wrappers](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/protocol.rs:109), [integer canonicalizer](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/protocol.rs:370).

The pinned Aeneas source explicitly rejects scalar float synthesis, so extracting all floating-point serde bodies is not currently an established workaround. [SynthesizeSymbolic](/var/tmp/behavior-ir-core036-v2/w001/tmp/nonpos-source/a0273/aeneas/src/symbolic/SynthesizeSymbolic.ml:78).

## Collections: the minimum includes order and mutable continuations

Use one finite ordered-map model and derive serde_json Map and BTreeSet from it. serde_json's selected non-preserve-order Map is directly backed by BTreeMap; translate/refine its thin source wrappers onto the generic map primitive rather than posit a separate arbitrary object encoding. [Pinned Map](/var/tmp/behavior-ir-core036-v2/w001/cargo/registry/src/index.crates.io-1949cf8c6b5b557f/serde_json-1.0.151/src/map.rs:29).

`Collections.lean` needs: new/empty, lookup/absence, contains, replacement insert and returned old value, remove and returned membership/value, len/is_empty, clone, structural equality using the supplied value comparator, entry/or_default, and borrowed/owned iterators (`iter`, `into_iter`, keys, values). The generated `get_mut` and entry functions return a value **plus a backward update continuation**: prove that applying it updates only the selected key, preserves membership/other keys and matches the mutation performed by the caller. Proving only ordinary get/insert is inadequate. [Actual326 signatures](/var/tmp/behavior-ir-core036-v2/w001/native-extraction/a0326/generated/FunsExternal_Template.lean:886).

Iterator laws must state complete exact-once coverage, sorted order, cursor advancement/exhaustion and snapshot/borrow behavior. Order matters for first errors, active-children arrays, JSON serialization and ordered command lists; a set-membership equivalence alone does not suffice. Preserve sequence duplicates. Cover Vec push/index/length and iterator map/filter/collect/any/all/peekable, sort/dedup/retain only where the selected transitive closure actually uses them. Prepared rule execution merges ordered maps; incremental reference maintenance sorts/deduplicates edge sequences. [Views iteration](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/views.rs:95), [prepared ordered merge](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/eval/prepared.rs:475), [incremental edge maintenance](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-store/src/store/incremental/mod.rs:214).

Bind ordering and borrowed lookup to actual String/str and EntityKey comparators; arbitrary inconsistent `Ord`/`Borrow` instances are not admitted by a string map theorem. The retained analysis rust source specifies ascending key order and lookup's Borrow/Ord bounds; that source is evidence for the analysis boundary, not by itself proof that the native compiler's std implementation is identical. [Analysis std BTreeMap](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/collections/btree/map.rs:34).

A narrow declared generic std map primitive contract can avoid proving tree balancing, allocation internals and atomics from Rust. Its finite representable domain, comparator laws, successful allocation assumption/error behavior and exact used API must be explicit. Source-refine the application seeding/staging/apply loops and their membership/absence invariants over that contract. If generic trust is rejected, a source-bound verification of native BTreeMap or an actual shared executable extraction-compatible map with proved adapters is still required. Replacing the implementation only in Lean is insufficient.

## Runtime: identities and performed effects cannot be erased

`Runtime.lean` should model Arc as a heap allocation identity plus payload and live strong/weak ownership, with clone preserving allocation identity, new producing a fresh live identity, ptr_eq comparing allocations, and get_mut succeeding only when uniqueness is established. Arc<()> epochs **cannot** become equality of unit payloads. PreparedSnapshot's child carries parent and fresh-next tokens; apply checks ptr_eq before promotion. CheckedEvaluation also checks its epoch, full module identity and parsed request. MatchedParent uses the actual Module borrow address. [Prepared source](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/eval/prepared.rs:16), [promotion](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/eval/prepared.rs:168), [reuse checks](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/eval/prepared.rs:236).

Do not assert addresses are never reused globally: model freshness among live allocations, with dropped handles unable to authorize later work. Uniqueness failure discards optimization in actual incremental carry; replacing `get_mut` with unconditional Some loses that branch. Include Weak semantics if the selected closure can create Weak handles. std ptr_eq compares allocation addresses; get_mut tests is_unique. [Analysis std Arc](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/sync.rs:2276), [get_mut](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/sync.rs:2791), [native caller](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-store/src/store/incremental/mod.rs:188).

Dynamic EvaluationFacts needs source-bound dictionary/dispatch for exists/used/incoming/query/field/entity, including default errors, actual selected implementation, state/history position and call/error order. A universal provider with a hypothesis saying it gives the canonical result would leave B05 open. Source-refine each dispatched adapter; then use dictionary-parametric evaluator lemmas where their hypotheses are discharged by those adapters. Charon monomorphization is not a proof of trait-object dispatch. [Actual trait](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/facts.rs:39).

Separate language panics/overflow from returned library/serde/I/O errors and from backend effects already performed. Aeneas Result includes panic/overflow/division errors and divergence, but its primitive Rust effect here is failure; it is not automatically a trace of OS writes or Store commits. Use an explicit world/trace relation for performed effects, including short/partial writes, flush/sync, commit acknowledgement, lost acknowledgement and quarantine. Keep poison/recovery paths for Mutex and actual checked arithmetic. [Aeneas Result](/var/tmp/behavior-ir-core036-v2/w001/analysis-runtime/a0035/package/backends/lean/Aeneas/Std/Primitives.lean:39), [contract B08/B09](../contracts/correctness.md).

1. Freeze a dependency ledger keyed by actual function/type/trait/monomorphization and pinned source/configuration. Record translated source, legitimate generic primitive, shared actual function, or open source refinement for every external. Actual326 has nine serde_core serializer bodies and two Read bodies, but many JSON/Store/codec calls remain external; include their transitive methods. Nine bodies do not establish the serializer or I/O boundary. Prove generated `text` and seed-row/seed-relations correctness against full versions, then `stage_sound`, `apply_confirmed_preserves_reconstruction`, invalidation and fallback. Preserve intermediate partial mutation and invalidation branches. These are T053–T056 prerequisites, not B10.
3. Build T058 relation: finite native key/row bijection plus full EntityVersions, arbitrary metadata/context, history/store/schema/writer/epoch and errors/effects. Keep a full-native payload component alongside the reduced Safety projection. 4. For B07 prove full invocation/bundle/commit/transition/history/state/outcome construction, equal source locations and metadata, then use congruence at the exact same `module_wire`, value/packet/record codecs or hash monomorphization. Invocation metadata contains commit_time/evidence/at and is forwarded to Store::invoke; these are part of the argument proof. Equal reduced Safety state or equal Value::PartialEq is insufficient. 5. Prove B08 successful byte/newline delivery and explicit failure traces, B09 confirmation-only authority advancement, then B10 repeated session composition including original fallback. Equal callback input implies equal pure output; effectful calls also need equal relevant world and compatible performed traces. An arbitrary callback returning the whole desired observation cannot replace its construction proof.
6. For T059/T070 inspect exact root types, premise domains, all transitive axioms (including those occurring through external types), actual source/generated-body/cfg identities and real source mutants. Distinguish the kernel's foundation list from separately declared generic-runtime adequacy. Keep unproved linkage marked unestablished. Hashes, 77 finite tests, 12 comparisons and representability/kernel loading do not replace any of these refinements.

Remaining limits are substantial: actual native compiler/analysis correspondence, collection/runtime adequacy, source-bound Core dispatch and prepared evaluation, Store/JSON adapter proofs, and effectful output/publication composition have not been supplied by this note. The recommended architecture reduces unnecessary numeric/codec internals; it does not make B01–B10 established.
