# I/O default methods: a defensible source/model boundary

Research only, 2026-11-18. This note uses the research skill and local primary sources. It writes only this new, unselected note. No builds, tests, downloads, implementation, selected-input/evidence edits, large IR parses, process-argument/environment inspection, or protected artifact access were performed. Actual344/root79727 was supplied as live; this investigation does not infer its outcome. Native329's reported 77 tests and twelve original byte comparisons remain conformance evidence, not native bridge proofs. T052/T059 and B01–B10 remain unestablished; current completed actual341 still fails full NativeFuns.

## Recommendation

**A narrow transparent model can legitimately factor each real default through the primitive methods it actually calls. It cannot, by transparency or source hashes alone, become a native refinement proof.** The smallest useful successor is a source-bound, dictionary-projected model of the real `Write::write_all`, followed separately by the larger `Read::read_to_end` helper model. Write needs the actual `write` field; Read needs **both** actual `read` and `read_buf` fields, exact cursor/vector behavior, and actual Take dispatch. Current generated Read does not even retain those primitive fields. Therefore this route still requires frontend/model integration and source/refinement work; it is not a two-definition template replacement that closes native proof.

This is permitted by the existing contract's distinction between translated source, explicitly justified generic runtime primitives, same-native-function congruence, and unresolved source refinements. The contract requires domain/source binding and says a model template is not a native refinement proof. T052 permits source-bound frontend/model support but forbids hidden unsupported nodes, alternate proof-only algorithms, or domain narrowing. T055, T067 and T069 retain effects, output completion and composition obligations. See [correctness construction and repair path](../contracts/correctness.md:30), [T052–T055](../tasks.md:112), [T067/T069](../tasks.md:127), [proof contract](../inputs/v2/proof-contract.json:18), and [FR-002/003](../spec.md:126).

The [File dictionary](/var/tmp/behavior-ir-core036-v2/w001/ground-lean-probe/a0341/project/WorkerEntrypointsNames/Funs.lean:273) passes itself to [axiomatic Write default](/var/tmp/behavior-ir-core036-v2/w001/ground-lean-probe/a0341/project/WorkerEntrypointsNames/FunsExternal.lean:150). The [transparent Read default and Take dictionary](/var/tmp/behavior-ir-core036-v2/w001/ground-lean-probe/a0341/project/WorkerEntrypointsNames/Funs.lean:397) pass the whole self dictionary to [axiomatic `default_read_to_end`](/var/tmp/behavior-ir-core036-v2/w001/ground-lean-probe/a0341/project/WorkerEntrypointsNames/FunsExternal.lean:1179). Thus the latter syntactic cycle is not evidence that the native helper calls `read_to_end` recursively; it is a consequence of an opaque whole-dictionary dependency.

The pinned [`impl_def` implementation](/var/tmp/behavior-ir-core036-v2/w001/analysis-backend/a0054/lean/Aeneas/Tactic/Elab/TraitDefault/Init.lean:161) unfolds tagged trait defaults, substitutes known field projections, and [rejects remaining self references](/var/tmp/behavior-ir-core036-v2/w001/analysis-backend/a0054/lean/Aeneas/Tactic/Elab/TraitDefault/Init.lean:261). Making the Read default transparent has already left its helper opaque. Simply exposing a non-default helper does not cause this tactic to unfold it. Either a source-bound projection must make the default mention only already-resolved primitive fields, or bounded helper unfolding must be added with the primitive dependencies retained. More fuel, exposing an axiom, or turning the whole dictionary into an opaque primitive supplies neither body nor dependency theorem.

The prior [frontend diagnosis](io-frontend-source-diagnosis.md:43) records actual313's slice metadata failure followed in retained LLBC by RawPtr creation/dereference. A metadata-only patch is not a justified claim that the real Write default translates. This note proposes an alternative **semantic normalization/model route**, not a conclusion that those frontend gaps have disappeared.

## Exact Write boundary

The pinned [native default body](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/core/src/io/write.rs:214) has this precise control flow:

1. An empty remaining slice succeeds without a `write` call.
2. Otherwise call the **actual receiver's `write` method** on the complete remaining slice.
3. `Ok(0)` returns the specific [`WRITE_ALL_EOF` error](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/core/src/io/error.rs:125), whose kind is WriteZero and message is “failed to write whole buffer”.
4. `Ok(n)` takes the checked suffix `buf[n..]` and repeats. Out-of-range `n` cannot silently become clamping or successful consumption; source slice/panic semantics must be preserved or unreachability proved for the relevant actual implementation.
5. An error satisfying the actual [`is_interrupted` classifier](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/core/src/io/error.rs:484) retries the same remaining slice; another error returns immediately. Preserve the complete error, state and performed effects.

A transparent model may take a projected `write` callback, rather than a `Write` dictionary containing `write_all`. Conceptually, `writeAllCore(write, state, remaining)` executes exactly that loop. The real trait default then projects `D.write` and invokes the core. This is a small representability seam because native source never reads `flush` or `write_all` in this body. The required dependence theorem is equality of this source computation for dictionaries with equal `write` semantics; it is **not** an assumption that the desired native observation equals the model. A useful universal theorem can be proved without assuming progress: an infinite sequence of Interrupted responses may diverge. A total-success/termination promise would add a new environmental assumption. These are deductions from the cited default body, not already checked theorems.

The callback's semantics must carry actual receiver state and any relevant external world/call trace, including outcomes on error, panic and divergence. The existing generated type `Result (ioResult × Self)` is a functional representation; merely declaring a callback of that type does not establish that OS writes or error-side effects have been modeled. The state/effect relation must be specified and checked at the declared runtime boundary under [T055](../tasks.md:115), and composed with the original output operations under [T067](../tasks.md:127). An explicit world model would be a prospective model extension, not an assumption accepted by this note.

**Do not infer “Err means no state/effect change.”** The actual [`Counted::write`](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/output.rs:32) increments its call counter before invoking `inner.write`, then checks its byte-counter addition **after** successful inner output. Thus an inner error can leave the call count changed, and a byte-counter-overflow error can occur after output was performed. A proof may establish that a particular overflow is unreachable; generic trait documentation cannot substitute for that proof. The model must preserve this implementation even where a stronger idealized writer law would be convenient.

Only instances using the default receive this model. [File's Write implementation](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/std/src/fs.rs:1519) and [Counted](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/output.rs:32) do not override `write_all`. [BufWriter does override it](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/buffered/bufwriter.rs:572), buffering a small input or entering its [cold path](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/buffered/bufwriter.rs:430); that path may flush first and call the **inner `write_all` override/default** directly. Replacing BufWriter's override with the generic loop changes dispatch, buffering and call/effect order. Its actual341 [dictionary correctly retains the override](/var/tmp/behavior-ir-core036-v2/w001/ground-lean-probe/a0341/project/WorkerEntrypointsNames/Funs.lean:378).

## Exact Read boundary

The [Read default](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/read.rs:290) calls `default_read_to_end(self, buf, None)`. The [helper source](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/read.rs:846) calls only primitive `read` and `read_buf`, not `read_to_end` or `take`. This supports a source-proved projection onto those two methods. **It does not support replacing both by one abstract “get next bytes” operation.**

The exact helper also observes and changes Vec length/capacity and initialized spare storage. It begins with `start_len`, `start_cap`, checked size-hint rounding, `init_until`, and a 32-byte probe. Under the actual selected cfg, the probe's allocation-before/after-read behavior must be preserved; the source has separate `no_global_oom_handling` branches. It retries Interrupted on `read`, appends the read prefix, and avoids some allocations by further probes. Its main loop reserves space, chooses a cursor size from capacity/initialization/max-read heuristics, creates a BorrowedBuf over spare capacity, and invokes the actual `read_buf` override. All these details come from the cited helper body, not a generic Read contract.

The main loop retries Interrupted using reborrows of the **same cursor**. It then reads the cursor's filled count, updates initialization tracking, extends Vec length, and **only then propagates the non-Interrupted error**. Data and an error can therefore coexist; bytes appended before error survive. [`BorrowedCursor::reborrow` and `written`](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/core/src/io/borrowed_buf.rs:308) share the filled count; `capacity`, initialized state, checked advancement, and [`ensure_init`](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/core/src/io/borrowed_buf.rs:454) are semantic state. Repeated interruptions must not reset cursor progress or discard its effects.

A faithful transparent helper model therefore needs the exact two callbacks plus buffer/cursor/vector state and allocation/error semantics. One possible interface is an internal `ReadOps` record containing `read` and `read_buf` with a checked interpretation of cursor operations, while the public native trait retains its complete selected behavior. A proof must show that the source helper factors through this record and that the source-to-model vector/cursor operations preserve initialization, bounds, aliasing and error order. A source hash plus a hand-written read/append loop does not show that.

Retaining only accumulated bytes is too weak for the generic domain. The trait explicitly permits a safe [`read` implementation to inspect the initialized input buffer](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/read.rs:117); different buffer sizes/contents can affect results or effects. `read_buf` may return data plus an error and may be overridden independently. Allocation choices change subsequent primitive requests and failure points. Capacity/initialization may be abstracted only after an implementation-specific observational refinement proves that abstraction valid, not by restricting all readers to an unmentioned ideal stream law.

### Preserve actual Take and File dispatch

The actual [`Take<T>` implementation](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/util.rs:235) overrides **both** primitives:

- `read`: at zero limit return zero without an inner call; otherwise cap the slice, call `inner.read`, check the returned count against the limit, and decrement after success. Preserve the assertion and the returned buffer/receiver state on error.
- `read_buf`: at zero limit return without an inner call; otherwise pass either a truncated temporary cursor or a reborrow. Preserve initialization propagation, possible zero-initialization of the remaining cursor, advancement, and decrement by bytes actually filled. It updates the limit **even when the inner call returns an error**, then returns that result.

For actual [`File::open(...).take(...).read_to_end(...)` callers](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/io.rs:11), the chosen `read_to_end` is Take's inherited default; its lower calls dispatch to Take and then File. [File forwards `read` and `read_buf` through `&File`](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/std/src/fs.rs:1497), whose [implementations reach the inner file operations](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/std/src/fs.rs:1325). Take does **not** call File's distinct `read_to_end` override. That [File override reserves using a file-size hint](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/std/src/fs.rs:1379); preserve it if reached elsewhere. The native artifact caller likewise retains its [declared byte limit and first-error/hash order](/data/repos/behavior-ir-core-033/experiments/transition-study036/src/native_artifacts.rs:103).

The trait's [default `read`](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/read.rs:167) delegates to `read_buf`, and [default `read_buf`](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/read.rs:409) delegates through `default_read_buf` to `read`. The [must-implement-one-of annotation](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/io/read.rs:86) is not a proof that arbitrary mutually recursive dictionary models terminate. Preserve actual selected overrides. Take and File provide both; no Read-to-end fixpoint is semantically required merely because an opaque extraction currently creates a syntactic whole-dictionary cycle.

## Minimum defensible implementation sequence

These are prospective work items; none was implemented or checked in this investigation.

1. **Write first, without changing executable Rust.** Add an exact source-bound default-method normalization/model mapping under T052. Emit a transparent default that projects only `write`, backed by a transparent partial loop implementing the pinned source's empty/zero/suffix/Interrupted/error cases. Bind the exact source span/body, selected cfg, tool and dependency identity. Reject source drift unless the model/refinement is updated. Do not replace a generated body after extraction. A targeted slice-suffix normalization with bounds/borrow proof can serve the same purpose; full general RawPtr support is unnecessary if the exact native operation is soundly normalized.
2. **Prove the Write source adapter and field-dependence theorem.** The native source computation must refine that loop over declared slice/error/state/effect primitives, or remain an explicitly unresolved source refinement. The theorem must quantify arbitrary admitted receiver states and callback behaviors, including panic/divergence, without a success/fairness assumption. Check that the existing `impl_def` can resolve it using the projected `write` field; do not unfold the loop recursively merely to resolve the dictionary.
3. **Read separately: retain dependencies before pruning.** Extend source/model dependency demand so `read`/`read_buf`, actual Take implementations and reached File methods are retained before current opaque-helper reachability prunes them. Select a source-bound helper model with the exact `ReadOps` projection. Either emit a transparent default projecting its two fields directly or add bounded, targeted unfolding of the helper wrapper. Keep unrelated fields and actual overrides intact. This is larger than Write because cursor/Vec/allocation semantics and their source bindings are mandatory.
4. **Prove Read factoring and actual adapters.** Prove that equal primitive semantics yield equal helper computations with the same vector/cursor/world state, then prove the Take/File adapters, error classifier and cursor/allocation relations at the actual instantiations. No whole-dictionary opaque callback may hide dependence on the field being constructed. A truly recursive callback remains partial; if NonPos/fixpoints are used, prove the actual functional's required continuity rather than declare it for the opaque helper.
5. **Freeze a fresh subject and recheck the full closure.** Include the newly reached dependencies, unchanged native implementations, complete generated inventory, expected theorem types, permitted axioms and native controls. Only later compose T053–T055/T067/T069. T052 representability and a passing helper do not set T059/composed status; [the task explicitly prohibits that promotion](../tasks.md:119).

The source algorithm adapter is mandatory on the model route. If no checked source semantics/normalization/refinement can establish it, the contracts require further frontend support or a justified prospective verification-method revision. Declaring the loop “transparent” and its source link “trusted” would merely relocate the unsupported body into a new assumption. The alternative executable-Rust refactor route must change the real shared workers and prove compatibility; a proof-only replacement/default override is disallowed by [the repair contract](../contracts/correctness.md:35).

## Trust and completion limits

Low-level OS read/write, allocation, error classification or slice/cursor primitives may have explicitly justified, source-bound generic models at the declared runtime boundary. Calling the entire native dictionary, `write_all`, `read_to_end`, or output-success relation a “generic primitive” is not automatically justified: their real control flow and effects are exactly what the source adapters above must account for. No new trust, fairness, finality, no-error, no-overflow, fixed-reader, bounded-fixture, or desired-result assumption is accepted here. [FR-003](../spec.md:128) and the [proof contract](../inputs/v2/proof-contract.json:18) retain those restrictions.

Shared original-function congruence remains available only after identical function identity, equal **complete** native arguments/state and compatible performed call/error/effect conditions are proved, as required by [the contract](../contracts/correctness.md:42). Equal byte arguments alone do not make two OS calls equivalent; a stateful or nondeterministic environment can distinguish them. Likewise, arbitrary callback quantification proves a generic algorithm theorem, not the missing proof that the actual native callback/override is represented by that callback.

The smallest honest outcome after the first successor is “source-bound Write default representable with a checked adapter over declared primitives,” with its actual remaining runtime bridge named. Read support requires the separate primitive-demand/cursor/helper work. Until those adapters, native instance relations and the whole expected closure pass, current full NativeFuns remains failing and all B01–B10/T052/T059 completion claims remain open.
