The Nix manual says `nix-shell` sets derivation variables, sources stdenv setup and runs `shellHook`; `--run` uses a noninteractive shell. `--pure` clears most inherited variables but retains some, and it does **not** select that launching shell: `NIX_BUILD_SHELL` is separate and its fallback can involve `<nixpkgs>` or PATH.
