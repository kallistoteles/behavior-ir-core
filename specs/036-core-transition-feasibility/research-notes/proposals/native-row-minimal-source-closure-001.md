## Decision

The minimum sound closure is the **current read/dependency graph**, with explicit immutable provenance boundaries, rather than the union of every preceding development input list. Keep current executable/controller sources, seven live model sources, the active selector and bindings, tool/environment/profile/control dependencies, four positive494 generated files, and exact retained producer/proof references. Preserve old Rust/cfg/source provenance through its original sealed subjects and checkpoints. Do not require today's mutant owner to equal positive494's old owner. This is consistent with the existing immutable execution-source resolver. [S1][S2][S3][S4][S5][S6]

However, a smaller list alone cannot prove completeness: `freeze` and `_subject` only validate the supplied rows; a needed file absent from that list can still be read successfully by `refs.verify`. Add an independently derived required-source membership check before adopting a reduced manifest as complete. Backend/Lake imports also require an explicit dependency audit described below. No existing check should be disabled. [S1][S3][S6][S7]

## What the controller actually requires

- `freeze` accepts exactly `{files:[...]}`, with 1–20,000 refs, rejects duplicate `(root_id,path)`, verifies every supplied logical ref, then snapshots its exact bytes. It has no rule requiring inheritance of a preceding input list, all old `.lean` files, reports, or all historical proof artifacts. [S1, `freeze`, lines 1588–1639]
- `_subject(current=True)` verifies each snapshot and its byte/hash equality to its logical ref, then verifies each current logical ref. It checks the list's schema, subject/spec/work identity and ownership, **not its completeness**. An old logical path may legitimately change after its recorded attempt; historical interpretation must resolve its old snapshot instead. [S1, lines 365–423][S6, lines 516–555]
- Declaration independently binds **all top-level `E/*.py`** as `executor_sources`; run checks those and the source subject before the child and again afterward. Preserve this entire executor set. Including the same files in the new source manifest is a useful explicit envelope, though the independent executor binding already exists. [S1, lines 600–622, 682–685, 1426–1432]
- `execution_control_paths()` includes `F/inputs/v2` and all regular experiment files except the top-level private/cache exclusions, plus the registered future evidence root at run time. This is accounting coverage, not a source completeness validator. Do not narrow it to the proposed manifest. [S1, lines 634–645, 1279–1292][S8]
- `FrozenSourceWriter` reads each selected input independently; it may hardlink exact bytes to a verified previous snapshot. It does not justify omitting needed inputs, avoid reading mutable inputs, or require copying the old input inventory forward. No reuse/deduplication change is proposed. [S2]
