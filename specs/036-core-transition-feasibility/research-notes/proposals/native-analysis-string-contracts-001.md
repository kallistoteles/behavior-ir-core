1. Generic `SlicePartialEq::equal_same_length` changes from indexed `while` with an explicit increment to `for idx in 0..len`, removing the const-hack comment. Both check the first unequal element and otherwise return true, but equal mathematical results do not establish equal lowered execution, cost or effect behavior. Both process equal-index elements in the common prefix and then call the length continuation; their lowered programs are not textually the same.
