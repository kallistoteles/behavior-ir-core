## Fixed filter and conservation contract

Use exactly this closed set of logical identities, matching **both** root and full normalized relative path:

```python
EXCLUDED = frozenset({
    ("repository", "specs/036-core-transition-feasibility/progress.md"),
    ("repository", "specs/036-core-transition-feasibility/IMPLEMENTATION-STATUS.md"),
})
```

No basename test, Markdown suffix rule, directory prefix, configurable exclude list, “documentation” classifier, recentness rule, or reachable-only replacement is justified. `tasks.md`, spec/plan/contracts, code, imports, sources, tools, models, expected theorem types, generated bodies, dependencies, producer/checkpoint/receipt refs and unrelated same-name paths remain required exactly as before. The record/path guards and explicit expected-context requirements remain intact. [Ref validation](../../../../experiments/transition-study036/records.py:228), [protected components](../../../../experiments/transition-study036/artifact_registration_v2.py:10), [expected context](../../contracts/reproduction.md:7).

For the first prospective transition, independently bind the existing N425 inventory through the already frozen r9556 manifest's input-manifest reference. Treat its list as the preservation baseline, not a candidate-selected replacement. Let `B` be that baseline, `A` the explicitly reviewed new producer/code refs, `C` the same inherited-and-appended inventory before filtering, and `O` the output:

1. Validate all reference shapes and every protected path component before any referenced path I/O. Reject duplicate keys before filtering, including duplicates of an excluded path; reject malformed paths rather than normalizing them into an exclusion.
2. Require `keys(C) = keys(B) ∪ keys(A)` with no silently removed baseline key and no undeclared addition. Refresh retained baseline bytes using the same root/path identities; document actual source changes normally. This preserves the current inline constructor's inherited-inventory behavior rather than substituting a generic closure algorithm.
3. Require `keys(O) = keys(C) − EXCLUDED`, `keys(C) − keys(O) = keys(C) ∩ EXCLUDED`, and `keys(O) − keys(C) = ∅`. For every retained key, its complete refreshed ref dictionary in `O` must equal that in `C`; preserve list order. Compare lengths as well as sets, so duplicates cannot disappear behind set equality.
4. For initial N425 with no additions the exact counts are **3,676 → 3,674** and exactly those two keys disappear. Later constructors must inherit all remaining keys and approved additions; absence of those two keys is then expected, without finding replacements to maintain a two-entry deletion count.
5. Verify every retained ref using existing registry/subject/source-gate paths before and after execution. Keep full compiled/native/import/call/tool/producer closure checks. Conservation only preserves an inventory; it does not prove the inherited inventory complete or sufficient for a native theorem.

This is a proposed contract, not an existing check. `_subject` and `checked_source_gate` currently accept the supplied inventory as their population and do not supply steps 2–3. [Subject population loop](../../../../experiments/transition-study036/controller_v2.py:401), [source-gate population loop](../../../../experiments/transition-study036/gates.py:107).

N425 has 3,676 distinct logical keys. Its progress ref is 466,386 bytes and its implementation-status ref is 4,702 bytes: **471,088 declared source bytes** would be excluded for that inventory. This is approximately 471 KB per future cycle in which both document contents change at their current sizes, not a guaranteed total resource reduction and not a 30 MB saving. N425 directly contains active `tasks.md` and `spec.md`, but no direct repository `plan.md` or `inputs/v2/initial-tasks.md` row. Do not infer that this absence proves those artifacts unnecessary or already transitively complete. Keep their original frozen intent/context unchanged; establishing any missing required binding is separate additive closure work, outside permission to remove these two paths.
