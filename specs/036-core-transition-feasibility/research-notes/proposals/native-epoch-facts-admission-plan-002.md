## The generic primitive must include uniqueness

Note001's identity-bearing new/clone/ptr-equality/drop/borrow model is necessary but insufficient for the actual call closure. `carry_incremental_child` calls `Arc::get_mut` on both cached `SeedFacts` and cached `PreparedSnapshot`. Failure of either clears the cache; success permits actual in-place mutation. Model erasure of ownership counts would change real fallback/retention behavior. [incremental/mod.rs:188](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-store/src/store/incremental/mod.rs:188).

Add this generic operation contract:

`get_mut : exclusive ArcHandle α → runtime → (Option(exclusive payload borrow α), runtime)`.

On the successful source domain, it returns `Some` precisely when no other strong Arc or Weak pointers share the allocation; the mutable borrow refers to the same allocation payload and supports updates reflected in that handle after borrow completion. Otherwise it returns `None` without cloning the payload or minting a fresh allocation. The uniqueness check synchronizes with reference-count changes. This is an ownership-sensitive result, not a predicate on payload equality. The actual analysis owner states the no-other-Arc-or-Weak condition and implements `get_mut` through `is_unique`, whose weak-count lock and strong-count load use atomic acquire operations. [sync.rs:2765](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/sync.rs:2765), [sync.rs:2791](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/sync.rs:2791), [sync.rs:2930](/var/tmp/behavior-ir-core036-v2/w001/analysis-toolchain/a0039/sysroot/lib/rustlib/src/rust/library/alloc/src/sync.rs:2930).

The current source inspection shows no Weak creation in these holder/carry owners, but that bounded inventory is not a global no-Weak theorem. Either prove these private allocations cannot acquire escaped strong/weak aliases, including transitive calls, or retain the possible `None` branch in the source model. A generic identity-only Arc wrapper with unconditional `get_mut = Some` is inadmissible. The native 1.98 Arc implementation/compiler relation still needs its own source binding; analysis implementation and stable annotations do not establish it.

The caller proof must track temporary `Arc<SeedFacts>`/`Arc<PreparedSnapshot>` handles across invocation and rederivation and their destruction before in-place carry. `CheckedEvaluation` retains `Arc<CheckedResult>` containing epoch Arcs, not an Arc to the entire `PreparedSnapshot`; these are separate allocation identities and separate ownership counts. [prepared.rs:45](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/eval/prepared.rs:45), [store.rs:1530](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-store/src/store.rs:1530). Do not confuse old epoch liveness, which prevents stale-address reuse, with uniqueness of the enclosing snapshot, which controls mutation.

Required source roots include equal complete resolved state/input/context/data-version/action arguments, string conversion/decoding relation, prepared/original evaluation refinement, and compatibility with the shared builder's actual fallible encoding/identity operations. ## Exact six-method dictionary and data semantics

The trait has exactly `exists`, `used`, `incoming`, `query`, `field`, `entity`; there is no `count` method. The first three are required methods. The last three have explicit error defaults, including query-instance/entity/field text. The query method contract permits results in any order. [facts.rs:39](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/facts.rs:39).

An explicitly justified ordinary compiler/runtime premise may say that a valid `&dyn EvaluationFacts` call selects the actual fixed implementation/default method for its live receiver and preserves its complete arguments, return/error, effects and borrow lifetime. This does not entail purity, arbitrary-provider consistency, dictionary interchangeability or query/count semantics. A dictionary model must include all six actual methods, including defaults, even when a separately proved LD8 call-domain result makes some unreachable.

`QueryRequest` carries the actual module, query node, definition, instance, captures and environment. Its `matches(candidate)` directly calls `eval::query_matches(module,node,env,candidate)` and maps the error to `FactError`. That function decodes the candidate according to the query's entity, creates an evaluator with empty facts and invokes `matches_value` at Phase S. These are Core semantic operations requiring source refinement; calling them is not an ordinary trait-ABI guarantee. [facts.rs:73](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/facts.rs:73), [eval.rs:1930](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/eval.rs:1930).

`Facts::exists` prioritizes explicit existence evidence, then complete-universe membership, otherwise errors; `used` only accepts recorded identity facts; `incoming` requires recorded reference facts. `Facts::query` evaluates all universe rows through `q.matches` and, if an explicit query fact also exists, checks definition/entity/captures/**ordered member vector** against the result; absent a universe it returns the captured member vector or errors. `entity` clones an actual universe row; `field` prioritizes explicit field evidence then row lookup. [facts.rs:126](/var/tmp/behavior-ir-core036-v2/w001/sources/a0003/core-reuse/crates/behavior-core/src/facts.rs:126). Native map order/full payloads/first failure therefore remain essential even though the trait's public query contract allows any output order.

The actual current invocation builds a `SnapshotFacts<B>` and later `Supplied`/`ValidatedProvider`, as recorded in note001. Prove its particular method bodies against actual complete snapshot state and historical backend position. Preserve the original `used` route to historical backend facts; current-state validity alone cannot replace it. For `TemplateFacts`, `query`, `field`, and `entity` are now confirmed to use the trait's error defaults; supported templates must prove these calls unnecessary or preserve the exact error. 1. No Pending returns immediately, leaving the existing cache as it was; this does not rebind it to a new head. A later reuse still needs the exact `SnapshotIdentity` check.

## Minimal remaining dossier, proof roots and controls

The admissible primitive predicate should now include `Arc::{new,clone,ptr_eq,deref,get_mut,drop}`, live module borrow pointer equality, exact fixed-method dispatch, allocator/refcount/atomic/aliasing/destructor conditions, and poison/error behavior of the actual Mutex wrappers. It must be bound to exact native/analysis source/compiler/cfg/target identities. It contains **no** proposition that prepared/original evaluation, queries, projection or complete observations agree.

Required actual source roots remain:

- **Ownership/identity:** generation identity distinguishes live allocation from equal payload; old result/child strong epoch handles stay live through comparison; temporary snapshot/prepared aliases are tracked through invocation/reproduction/drop and `get_mut`; nonunique mutation follows cache discard; fresh/restarted sessions cannot import authority or revive freed addresses.
- **Certificate/state:** actual full validation establishes complete typed/canonical facts and history/schema/module/profile relation; cache replacement/retention preserves it; arbitrary finite native rows/JSON/IDs and Usize/UTF8 relations are included.
- **Method semantics:** prove all reachable concrete methods/defaults and `QueryRequest::matches` against actual state/history, exact call order, errors and full data; prove LD8 direct prepared count/member/row-template refinement separately. The trait/compiler premise ends at dispatch to these actual bodies.
- **Adapter/reproduction:** prove actual complete resolved request arguments, actual evaluator result/observations, first-difference and profiles, private hint provenance and common envelope arguments/effects; no equality callback or a supplied decision tuple is authority.
- **Publication/session:** prove Pending parent/child/hashes and dependency guards, post-Applied in-place carry, failures/uncertain acknowledgement, writer revocation/restart, and whole Ground continuation. Keep B03/B05/B09/B10 mandatory, including the actual Capture host/aliasing/CAS contract outside these owners.

Additional controls made concrete by these owners: hold a second facts/prepared Arc and check carry discards cache; exercise any reachable Weak alias; old-epoch pending child fails after successful apply; equal JSON under a different allocation/history cannot bypass association; a changed stored record fails full comparison despite a valid hint; wrong request/module/create-lifecycle prevents hint reuse; force actual default-method errors without replacing them by total answers; reject Candidate-as-complete-universe; no-Pending after Applied must not relabel old cache as child; failed/head-moved/lost-ack paths must never call successful carry.
