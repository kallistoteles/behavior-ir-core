# Prospective generated-row abstraction controls

Unselected test plan. These controls have not been executed. The row model,
structural audit and native/runtime correspondence remain unestablished.

Use the fixed actual494 generated Types/Funs and independently selected eight
root types. Keep original files unchanged; each mutation belongs to a fresh
owned proof project with its own source/command/exit records. A nonzero exit is
not by itself a successful semantic negative: retain the specific failing
obligation and a separate positive source/kernel run.

| Mutation/control | Required distinguishing result |
| --- | --- |
| Define RowRead as the original fixed caller, ignoring its dictionary argument | The independent elaborated-body audit rejects it, even if the instantiated bridge and a trivial noninterference theorem compile. The audit requires the exact four capture-avoiding replacements and exact reinstantiation. |
| Abstract only three read sites or modify another expression/literal | Structural source comparison rejects the unmatched body or site count. No instruction, branch, implicit argument or universe may be changed under the abstraction. Only nonsemantic expression metadata may be erased consistently. |
| Redefine ReadEq as False or a success-only relation | Independent audit rejects the predicate. It must compare complete read Result values at every key/value, including fail/div, rather than making noninterference vacuous. |
| Value.index invokes a mutable callback before reading | The universal value_index_exact/read-congruence roots cannot establish the unchanged statement for arbitrary full dictionaries. Preserve a concrete pair with equal reads and different mutable behavior as the distinguishing example. |
| Shared read ignores its supplied dictionary | The universal shared_read_exact root rejects the changed dispatch. A check only for the fixed Str instance is insufficient. |
| Pass the whole dictionary to an unclassified callback, return/store/capture it, inspect mutable fields or compare dictionary identity | The consumer/no-escape audit must reject the new use or require a new independently checked consumer relation. A return-type label alone is not a no-escape proof. |
| Remove mutable fields, replace generated bodies, substitute stale source or omit a declaration | Byte/source binding or complete expected-root/dependency checking rejects; no opaque target-equivalence axiom is allowed. |
| Equal reads both fail or both diverge, with arbitrary distinct mutable callbacks | Positive full-result noninterference must continue to hold. It must not turn failure/divergence into successful Null lookup. |

The two inert Str mutable definitions are explicit model inhabitants for this
restricted observational relation; they do not admit the native mutable APIs.
Shared mutable definitions must genuinely forward to their supplied records.
All four signatures and fields remain. Kernel closure still permits only
propext, Classical.choice and Quot.sound.

These controls establish neither the independent canonical row result nor
native allocation, panic/unwind, error-observation, Store/view or Core
composition. Those remain separate required proofs and actual-source checks.
