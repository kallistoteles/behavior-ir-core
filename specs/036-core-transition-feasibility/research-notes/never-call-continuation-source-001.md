## CPS shape and insertion point

`stl_cm_fun` returns a list of successor contexts/results plus a continuation consuming exactly that many expressions. `cf_empty` accepts `[]` and returns its captured expression. `comp_seqs` partitions continuations by successor-list length, including zero. Thus `([], cf_empty ... (cc SA.Panic))` is a legitimate terminal result, provided the caller remains symbolic. Existing symbolic handling of panic, unwind termination, and undefined behavior already uses `([], cf_empty ... SA.Panic)`. See [Cps.ml:31](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/Cps.ml:31), [Cps.ml:86](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/Cps.ml:86), and [InterpStatements.ml:953](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/InterpStatements.ml:953).

Statement sequencing evaluates the remainder only for each returned `Unit` context. An empty context list therefore stops evaluation of that branch's common successor, while its captured expression still participates in branch synthesis. See [InterpStatements.ml:831](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/InterpStatements.ml:831).

The proposed final conditional is correctly placed after the existing `cc` composition, not before argument evaluation or in place of call synthesis:

```ocaml
if inst_sg.output = TNever then
  ([], cf_empty __FILE__ __LINE__ span (cc SA.Panic))
else
  ([ (ctx, Unit) ], cc_singleton __FILE__ __LINE__ span cc)
```

The function first evaluates operands, creates region abstractions, composes `synthesize_regular_function_call`, assigns the fresh symbolic return into its destination, and optionally ends no-loan abstractions for unit returns. Its existing final unconditional `Unit` result then assumes success. Preserving all preceding operations preserves their continuation wrappers and their validation/errors. The call synthesizer wraps the tail as `FunCall(call, e)`, so applying `cc` to a terminal tail retains the call and earlier argument effects in the symbolic tree. See [InterpStatements.ml:1526](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/InterpStatements.ml:1526), [InterpStatements.ml:1639](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/InterpStatements.ml:1639), [InterpStatements.ml:1707](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/InterpStatements.ml:1707), and [SynthesizeSymbolic.ml:117](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/symbolic/SynthesizeSymbolic.ml:117).

This final change cannot fix a failure occurring earlier during operand evaluation, abstraction construction/ending, or destination assignment: those operations still execute before the guard. That is a conservative property, not proof that every `Never` call is supported.

## Why a dummy panic tail can preserve modeled call behavior

The Lean model defines `Never` as an inductive type with no constructors. `Result α` is an interaction tree, with separate failure and divergence; bind delegates to interaction-tree bind. `bind_fail` preserves the original error, `bind_div` preserves divergence, and `bind_vis` preserves the visible effect and composes beneath it. See [Primitives.lean:465](/var/tmp/behavior-ir-core036-v2/w001/analysis-backend-build/a0058/lean/Aeneas/Std/Primitives.lean:465), [Primitives.lean:52](/var/tmp/behavior-ir-core036-v2/w001/analysis-backend-build/a0058/lean/Aeneas/Std/Primitives.lean:52), [Primitives.lean:68](/var/tmp/behavior-ir-core036-v2/w001/analysis-backend-build/a0058/lean/Aeneas/Std/Primitives.lean:68), and [Primitives.lean:253](/var/tmp/behavior-ir-core036-v2/w001/analysis-backend-build/a0058/lean/Aeneas/Std/Primitives.lean:253).

Source inference: for `m : Result Never`, every continuation `Never -> Result β` is extensionally equal by empty elimination. Consequently a constant dummy-panic continuation has the same bind as an empty-elimination continuation. This does **not** identify `m` itself with panic: the retained call may fail with a different error or diverge, and those outcomes remain upstream of the unreachable tail. No theorem was compiled here. This argument requires a correctly typed empty return component and retention of the original monadic call.

The pure translator keeps `TNever` as `TNever`, prints it as `Never`, and normally translates the retained call into a let whose monadic flag is the callee's `can_fail`. Its forward-output omission is a unit-specific optimization, based on the uninstantiated output. It does not itself justify dropping a `Never` output/call. See [SymbolicToPureTypes.ml:172](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/symbolic/SymbolicToPureTypes.ml:172), [SymbolicToPureTypes.ml:745](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/symbolic/SymbolicToPureTypes.ml:745), [ExtractTypes.ml:543](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/extract/ExtractTypes.ml:543), and [SymbolicToPureExpressions.ml:708](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/symbolic/SymbolicToPureExpressions.ml:708).

## Concrete downstream pitfalls and conservative scope

- **Unused binding is not a license to erase the call.** `filter_useless` replaces unused patterns with `_`. It removes an unused non-monadic let unconditionally; for monadic lets, it removes only expressions recognized as always returning `ok`, or a specific redundant indexing pair. A regular opaque `slice_index_fail` call followed by panic is neither recognized case. There is no blanket “later panic subsumes any prior failure” rule in these predicates. Preserve a monadic call; check generated output after all passes. See [PureMicroPassesGeneral.ml:1172](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/pure/PureMicroPassesGeneral.ml:1172), [PureUtils.ml:1545](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/pure/PureUtils.ml:1545), and [PureUtils.ml:1592](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/pure/PureUtils.ml:1592).
- **Effect metadata matters.** Ordinary non-global, non-builtin functions are forced fallible in this source. Builtin/global exceptions remain. `can_diverge` does not by itself make a call's let monadic; `can_fail` does. A generic application to all `TNever` outputs must audit non-fallible builtin exceptions: an unused pure binding could disappear, losing a divergent computation. Also `SA.Panic` translates to a `Result.fail` expression; a caller classified pure may reject that body type. Verify callee and enclosing function are modeled fallible for the initial case. See [FunsAnalysis.ml:240](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/llbc/FunsAnalysis.ml:240), [SymbolicToPureTypes.ml:716](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/symbolic/SymbolicToPureTypes.ml:716), [SymbolicToPureExpressions.ml:808](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/symbolic/SymbolicToPureExpressions.ml:808), and [SymbolicToPure.ml:35](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/symbolic/SymbolicToPure.ml:35).
- **Borrows and generic calls require additional review.** Generic outputs instantiated to `Never` are semantically empty, but calls may still construct and return backward-function components in their translated tuples. Inputs containing borrows still create abstractions and continuations even when the output is `Never`. The zero-successor API is valid, but this review does not establish all abstraction-lifecycle or backward-function translation cases. Initial conservative scope: regular statically identified callee, exact normalized instantiated `TNever`, scalar/no-borrow signature, empty abstraction-region hierarchy, fallible callee and caller. Do not recognize arbitrary empty ADTs, name-match panic functions regardless of type, or replace the original call with panic. See [InterpStatements.ml:1588](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/InterpStatements.ml:1588) and [SymbolicToPureExpressions.ml:432](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/symbolic/SymbolicToPureExpressions.ml:432).
- **World/Native/I/O boundary.** The inspected `Primitives.lean` effect alphabet has only failure, with empty response type; it supplies no World/native-I/O refinement. No `World` definition was found by a bounded definition search of the given `Std` subtree. Keeping a modeled interaction tree's failure/divergence is not evidence about external world state, actual I/O, native behavior, unwinding, or Core feasibility. See [Primitives.lean:51](/var/tmp/behavior-ir-core036-v2/w001/analysis-backend-build/a0058/lean/Aeneas/Std/Primitives.lean:51) and the explicit unsupported unwind resume at [InterpStatements.ml:960](/var/tmp/behavior-ir-core036-v2/w001/disposable/frontend-translator-a0406/workspace/aeneas/src/interp/InterpStatements.ml:960).
