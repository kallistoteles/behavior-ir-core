## Subject and required relation

For arbitrary finite representable inputs admitted by the actual LD8 `finish` selector and explicitly enforced environmental premises E:

`Obs(Native036(x,E)) = Obs(OriginalCore(x,E))`.

Obs is the complete original invocation, bundle, commit arguments, transition record, before/after history, post-state and original property outcomes, including applicable canonical bytes/identities, first errors/refusals and ordered duplicate commands. Safety of the resulting state is weaker. Fixture N/H and parser measurement caps are not theorem bounds. Outside the selector, prove use of the same original fallback with equal complete inputs and compatible errors/effects; do not introduce a new refusal to simplify proof.

Record exact semantic/source/model/tool/configuration/backend/endpoint subject and callable entrypoints. The native stable/extraction compiler relation is explicit; extraction-only alternate algorithms or unchecked cfg divergence are forbidden. No claimed proof is created by a matching source digest, old model law, finite test or report flag.

### Shared original function congruence

It is unnecessary to reprove SHA or an unchanged serializer merely to prove equal applications of the same actual function. First prove identical actual function identity, equal complete native arguments and compatible performed call/error/effect conditions. Universally quantifying such a function is then honest congruence. An arbitrary `originalEncoder` callback applied to a simplified model is not a proof of native wrapper/context correctness.

B is fixed-role GV plus 64 KiB buffering around the same original serializer and newline. Use create-new output, handle explicit flush/extraction errors, then synchronize the underlying File before success. Prove equal successful byte stream and the actual wrapper protocol. Record bytes and underlying Write calls; do not call them syscalls without separate actual syscall measurement.

Controls cover create collision, serializer failure where representable, short writes, write/flush/sync failure and failed partial output. A backend commit may already have been acknowledged when delivery fails: do not pretend rollback or infer an unknown state. Retain the actual confirmed/uncertain head, reconcile before dependent continuation where needed, and never report completed delivery. Importing result/evidence flags never creates authority.
