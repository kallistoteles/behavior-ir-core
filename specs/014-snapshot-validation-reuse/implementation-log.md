snapshot_reuse -- --nocapture` collected seven tests. After correcting the test
fixture's parameter spelling, four passed and three failed on the intended
regressions:

- `same_snapshot_validation_is_reused_by_reads_and_evaluations`: warm read
  enumerated the universe (`keys_at` 1, expected 0).
- `local_commit_carries_validity_without_reading_the_universe`: commit revalidated
  10 entities (`keys_at` 1, expected 0).
- `global_rule_models_reuse_only_the_same_snapshot`: repeated same-snapshot read
  enumerated the universe (`keys_at` 1, expected 0).

The 64-case generated store-sequence comparison was also collected before
implementation and passed against the original full validator. It exercises
valid/invalid/no-op writes and canonical decision, bundle, head and read equality.
It is equivalence evidence, not an expected performance regression failure.

The classifier unit tests and 256-case direct changed-obligation/full-validator
comparison were added as supplementary verification after the first implementation;
they do not establish separate historical test-first evidence. The latter covers
two entity types, multiple changed fields, no-op/empty updates, invalid scalar
types, wrong identities, missing fields, invalid constraints and rule evaluation
errors, starting from valid complete parents.

checks the module against it, and never resolves that historical binding through
a later schema generation. The existing regression seed is retained unchanged.
This failing gate is not recorded as successful validation.

After the correction, the focused migration-tampering property completed
successfully (including saved seeds and generated cases, 277.79 s in unoptimized
test profile). The complete gate run is repeated on the corrected source.

latency claims and not a comparison to a different historic wheel. Initial
measurements made during another build were superseded by this final run.
Deterministic backend-call regressions, rather than timings, are normal CI gates.
Complex models and complete-universe record profiles retain their documented
costs. The final changes remain local/uncommitted; no publication has occurred.
