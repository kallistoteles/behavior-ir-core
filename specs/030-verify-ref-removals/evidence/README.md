## Mathematical claims and remaining limits

The private residual count is unrestricted mathematics, not runtime state or a
population cap. Typed finite-set partition and exact simultaneous delta justify the
sufficient child-entry implication for arbitrary finite valid parents. The implication
assumes only the actual earlier successful prefix, never later child/global/integrity
success. The real class preservation checks are separately emitted and inventoried.

Z3 discharges the actual SMT obligations. [The argument](../correctness.md) is reviewed
mathematics; 904-world enumeration and mutations are implementation/correspondence
evidence, not universal proofs. No Lean-kernel proof of Rust extraction or Core is
claimed. Core semantics, typed extraction, Z3, witness reconstruction and backend
completeness remain explicit trust boundaries. Genesis, migrations and host deployment
continuity require their own premises.

Existing unsupported same-type child order/nonlocal rules and optional query forms
without established totality remain explicit conservative limits. A failed bounded
candidate or computational exhaustion gives no proof and no invented counterexample.
Ordinary Id is not weakened into Ref, and no runtime persistence/replay dependency
was added. No feature was expanded to solve migration or general relational reasoning.
